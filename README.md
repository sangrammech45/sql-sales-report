# Sales Report: SQL Practice Project

**Author:** Sangram Jamdade

## Goal
Answer three common business questions about a small online shop using SQL: which regions earn the most, how revenue changes month to month, and which products sell best.

## Data
A synthetic (made-up) SQLite database, `sales.db`, generated by `seed.py`. It has 4 tables: `customers` (200), `products` (12), `orders` (1,500), and `order_items`. Orders cover January to October 2026. No real customer data is used.

## How to run it
```bash
python3 seed.py                      # builds sales.db
sqlite3 sales.db < queries.sql       # runs the three reports
```

## Findings
- North and South together bring in about 57% of total revenue (about $111.8K of $196.0K).
- Revenue swings month to month. August is the peak at $23,649, a 40.1% jump after a weak July.
- Backpack is the top product at $41,123, about 21% of all revenue.
